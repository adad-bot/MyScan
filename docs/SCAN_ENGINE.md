# موتور اسکن سند (DocumentScanEngine)

موتور مستقل و قابل استفادهٔ مجدد برای اسکن سند در اندروید.
کد در `app/src/main/java/ir/scanfa/app/scan/DocumentScanEngine.kt` است و به UI وابسته نیست؛
می‌توان همان فایل (به‌همراه `Warp`, `Enhance`, `Quad`, `SmartScan`) را در برنامهٔ دیگری برد.

## API

```kotlin
// تشخیص قاب سند
val detection = DocumentScanEngine.detect(bitmap)
detection.quad        // چهار گوشهٔ سند (اگر پیدا شود)
detection.confidence  // ۰ تا ۱؛ زیر ۰٫۳۵ یعنی تشخیص مطمئن نیست

// برش و صاف‌کردن (اگر quad نداشته باشیم خودش تشخیص می‌دهد)
val cropped = DocumentScanEngine.crop(bitmap, detection.quad, maxSide = 2200)

// یکسان‌سازی روشنایی + کنتراست + اشباع رنگ + تیزکردن
val enhanced = DocumentScanEngine.enhance(cropped)

// خط لولهٔ کامل
val scanned = DocumentScanEngine.scan(bitmap)
```

## الگوریتم

1. **تشخیص با سازگاری پیکسلی از مرکز**: رنگ میانگین یک وصلهٔ ۱۳×۱۳ در مرکز تصویر گرفته می‌شود
   و از همان نقطه با BFS/Region-Growing به سمت لبه‌ها رشد می‌کند؛ هر پیکسل که اختلاف رنگی‌اش
   با رنگ مرکز کمتر از آستانه باشد جزو سند است. پس متن، مهر و سایه‌های داخل سند باعث قطع شدن نمی‌شوند.
2. **پاک‌سازی ماسک**: dilation و سپس erosion برای پر کردن حفره‌های متن.
3. **مرزها**: برای هر سطر و ستون، اولین و آخرین پیکسل سند پیدا می‌شود.
4. **برازش خط و گوشه‌ها**: از نقاط مرزی چپ/راست و بالا/پایین، خط کمترین مربعات برازش می‌شود و
   محل تقاطع خط‌ها چهار گوشهٔ سند را می‌دهد؛ به این ترتیب کجی و شکستگی لبه‌ها جبران می‌شود.
5. **برش**: نگاشت پرسپکتیو (Warp) و سپس بریدن لبه‌های باقی‌مانده با همان روش سطر/ستون معنادار.
6. **یکسان‌سازی روشنایی**: روشنایی پس‌زمینه با میانگین‌گیری چندپاسه در یک شبکهٔ ۲۴ ستونی برآورد
   می‌شود؛ هر پیکسل تقسیم بر روشنایی محلی همان نقطه می‌شود. نتیجه: سایه یا نقطهٔ پرنور به‌صورت
   **محلی** اصلاح می‌شود، نه اینکه کل صفحه روشن/تیره شود.
7. **بهبود نهایی**: کشش کنتراست (درصد ۲ تا ۹۸)، اشباع رنگ ۱٫۲۸ برابر و unsharp mask برای تیزشدن متن.
8. **حالت دستی**: اگر `confidence` پایین بود یا کاربر خواست، می‌توان چهار گوشه را دستی داد
   (لازم نیست مستطیل کامل باشد) و همان `crop` + `enhance` اعمال می‌شود.
